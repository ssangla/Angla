PWA Icon Generator

Generate all required PWA icon sizes from a single image. For best results, use a square image (at least 512x512px) with your logo or brand mark.

Upload Your Icon

Supported formats: PNG, JPG, SVG (recommended: 512x512px or larger)

Instructions

  1. Upload your logo or icon image (square format recommended)
  2. Click "Generate Icons" to create all required sizes
  3. Preview the generated icons below
  4. Right-click on each icon to save individually, or click "Download All" for a ZIP file
  5. Place the downloaded icons in the /images/ directory
  6. Update the manifest.json file if you changed the filenames

Required Sizes: 72x72, 96x96, 128x128, 144x144, 152x152, 192x192, 384x384, 512x512
